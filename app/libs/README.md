# Samsung Health Data SDK

To build and run this Android project, place the official Samsung Health Data SDK `.aar` file in this directory:

- Expected file name: `samsung-health-data-api-1.1.0.aar`
- Download: Register on the [Samsung Developer Portal](https://developer.samsung.com/health) and download the **Samsung Health Data SDK**.

> **Note:** The proprietary SDK binary `.aar` file is excluded from Git according to `.gitignore` and Samsung's SDK license terms.
